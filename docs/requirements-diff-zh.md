# Diff 审阅与恢复

更新：2026-10-18。入口：[分类索引](requirements-zh.md)。

## 本轮修复与开发

- [x] 新轮次审阅默认单栏；等待宿主异步默认值落定后再切换，不覆盖同一页后续手动选择的分栏模式。
- [x] 同意后恢复普通背景和文字、隐藏删除侧旧行；Ctrl+Z 恢复红绿对比。拒绝后保留旧内容为普通状态，块内可重新审阅。
- [x] 独立审阅工具栏与文件选择/视图工具分开；完成时只展示统计和撤销，恢复键盘焦点，避免最后一次同意后 Ctrl+Z 失效。
- [x] 窄于 640px 的面板把块操作移到文字下方；长换行行不被 flex 压缩裁切；浅色/深色使用对应主题普通背景。

- [x] 连续改动行合并为一个更改块；官方轮次页、会话 Diff 和工作区 Diff 按块计算进度、决定和导航。官方每块只在最后一个可见改动行放一组按钮。
- [x] 文字与操作使用独立网格列，覆盖统一、换行分栏、普通分栏；使用宿主实际 Diff 样式进行 Chrome 长文本几何检查，文字与按钮不相交。
- [x] 顶部直接显示 Ctrl+K 同意、Ctrl+J 不同意、Ctrl+Z 撤销。旧逐行快照按当前磁盘中的剩余变化重新分块，不改变已写入的文件内容。

- [x] 轮次页顶部同时提供当前一处「同意 / 不同意」和批量「全部同意 / 全部不同意」；上下箭头定位上一处/下一处，Tab 可正常聚焦各按钮。

- [x] 官方“第 N 轮改动”页面按连续更改块注入同意/不同意，不再仅有顶部文件级按钮；使用官方 `data-changes-review`、`data-diff-line` 和行号定位，支持统一、左右分栏及换行布局。
- [x] 官方页面接入上一处/下一处、决定后定位、撤销上一步、Ctrl/Cmd+K/J、Ctrl/Cmd+Z、批量处理与决定恢复。撤销上一步保留准确的原决定，包括“已撤销改为保留”后的回退。
- [x] 官方页面的新增字与背景用绿色、删除字与背景用红色，当前行有边框，已处理按钮有选中状态；颜色只作用于对应审阅页，关闭时移除注入节点和监听。

- [x] 独立 Diff 标签恢复时保留有效的工作区/提交对比参数、分屏和活动标签，不再统一丢弃。
- [x] 变更面板记住选中的文件/操作，重新打开后恢复对应对比；关闭预览会清除该选择。
- [x] 会话编辑和已跟踪的未暂存工作区文本改动接入按块保留/撤销，处理当前块后定位下一处待处理改动。
- [x] 保留/撤销可在行边再次切换，当前面板提供撤销上一步；写入期间阻止重复操作。
- [x] 持久保存原始对比、逐行决定和当前改动位置。重新加载时校验磁盘内容，保留原始对比，而非把剩余差异当作全新审阅。
- [x] 持久化保留审阅模式，按连续块恢复决定；旧逐行记录以当前磁盘内容重新分块，不写回或丢弃已生效的内容。
- [x] 无前置读取记录的编辑，可从完整文件内唯一的新文本反向还原原始版本；无法确定时保留只读对比和说明。
- [x] 下一处改动超过正常渲染上限时自动显示该行，避免跳转目标和操作按钮不存在。
- [x] 同一操作的轮询刷新不清空审阅；切换文件后旧写入结果不覆盖新文件界面；写入使用 mtime 冲突校验。
- [x] 同意/拒绝后的块直接写入“普通内容”外观（行底色与文字色内联覆盖，隐藏被消除的一侧）；撤销时恢复宿主原本的内联样式与红绿对比，而不是把宿主样式删掉。
- [x] 撤销栈持久化到本地存储（最多 12 步，按容量保留最新若干步），宿主重新挂载或刷新页面后仍可撤销上一步；焦点落在页面空白处时 `Ctrl+Z` 也作用于当前可见的审阅页。

## 尚待补齐

- [ ] 已暂存内容、历史提交、二进制、已删除文件的不同操作语义与入口；当前历史/暂存对比保持只读，不能把操作写到其他版本。
- [ ] 新增/未跟踪文件撤销的完整恢复语义，不能用清空文本代替恢复文件不存在的状态。
- [ ] 存储空间不足的可见提示、快照容量管理与导出恢复。
- [ ] 真实宿主重启、不同分屏焦点、超大文件和外部同时修改的交互验收。

验证入口：`changes-op-review`、`diff-git-target`、`changes-tab`、`review-model`、`state`。组件重新挂载模拟重启恢复，不代替真实宿主重启验收。
