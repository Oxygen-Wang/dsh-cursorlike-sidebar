# 编辑器基础需求

更新：2026-10-18。入口：[分类索引](requirements-zh.md)。

## 已有能力

- [x] 文本编辑、语言高亮、Ctrl/Cmd+S 保存、脏状态、未保存关闭保护。
- [x] 保存时保留原文件编码/换行，基于 mtime 检测外部修改冲突；对应 `text-encoding`、`text-editor-conflict`、`editor-unsaved-guard` 测试。
- [x] 已有 Ctrl/Cmd+F 搜索面板、大小写/整词/正则开关；`text-editor-search` 与 `editor-find` 覆盖。
- [x] 打开文件时的行号跳转和编辑/预览切换；对应 `text-editor-line-jump`、`editor-line-nav-mode`。
- [x] 选中文本 Ctrl/Cmd+L 或拖入聊天，输出文件路径与行号，复用同一引用模型。

## 待补齐

- [ ] P0：全局 Ctrl/Cmd+P 快速打开，搜索结果键盘上下/Enter/Escape；文件区的文件名搜索不能算此项完成。
- [ ] P0：查找与替换的完整产品入口，Ctrl/Cmd+H、替换当前/全部、错误正则反馈；现有搜索 API/快捷键注册不能代替整条流程验证。
- [x] 多改动块逐块保留/拒绝、上一个/下一个和撤销处理已有相关组件回归；Diff 的持久恢复与未完成范围见 [Diff 专项](requirements-diff-zh.md)。真实宿主集成验收仍保留。
- [ ] P1：编辑区右键命令覆盖撤销/重做、剪切/复制/粘贴、引用、复制路径；键位说明与系统权限降级。
- [ ] P1：编辑导航前进/后退、最近文件、跳转行入口、文件面包屑。
- [ ] P1：拖文件到编辑区域打开/分屏；拖选中文字仍仅发送引用，不搬运源文件。
- [ ] P1：统一展示只读、二进制、大文件、权限失败状态，附带可执行的重试/下载入口。

## 范围外

Tab AI 补全、完整 LSP、自动重构/格式化服务、调试器、代码运行器、内联 AI 改写不属于本轮基础操作。
