# 文件浏览器需求：视图补全、拖拽、右键菜单与文件操作（2026-10-18）

> 状态：**需求（待确认）**，尚未开始实现。
> **一句话**：把文件浏览器从「树形全能、网格 / 多列只读」升级为四种视图统一操作；拖拽补齐移动 / 复制 / 上传 / 引用四种语义；右键菜单由一份动作表生成；补齐复制 / 剪切 / 粘贴与常用快捷键。
> 关联：[总需求与路线图](requirements-zh.md) 的 §0、§4.4–4.6、§5；实现时以代码与 [宿主契约](host-contracts.md) 为准。
> 本文把「几种文件夹展示还没有支持」理解为**文件浏览器的展示/视图模式**（§1）。如果用户指的是其他展示形态（例如会话里的文件夹卡片、产物体），只需替换 §1，其余章节仍然成立。
>
> 术语：
>
> - **文件区**：Files 页签里的浏览区域（树形 / 图标网格 / Miller 多列 / 列表）。
> - **条目**：一个文件或文件夹。
> - **当前目录**：网格 / 列表 / 多列面包屑的末端；树形中是当前展开的可见层级。
> - **内部拖拽**：文件区内部条目之间的拖拽（移动或复制），区别于「拖到聊天 = 引用」和「OS 文件拖入 = 上传」。

## 0. 现状快照（代码事实，2026-10-18）

| 能力 | 现状 |
|---|---|
| 视图 | **三种**：树形、桌面图标网格（默认）、Miller 多列；视图选择存在 `localStorage`，是**全局**偏好而不是按工作区（[TreePanel.tsx](../src/client/TreePanel.tsx:48)） |
| 排序 | **只有树形**有排序菜单（名称 / 类型 / 文件夹优先），且不持久化；网格与多列完全忽略排序（[TreePanel.tsx](../src/client/TreePanel.tsx:157)） |
| 树形操作 | 右键菜单最全：打开方式（宿主 + 插件）、新标签 / 侧边打开、下载、上传到此、新建文件 / 文件夹、压缩下载、复制相对 / 绝对路径、重命名、删除；多选批量条（复制路径 / 删除 / 清除）；行内重命名与新建；OS 文件拖入上传（[FileTree.tsx](../src/client/FileTree.tsx:2331)） |
| 网格操作 | 打开 / 新标签 / 侧边 / 引用 / 复制路径；**没有**选择模型、重命名、删除、上传、新建、下载、压缩、打开方式、空白区菜单；键盘只有返回 / 面包屑；Ctrl+滚轮缩放与图片缩略图可用（[FileGrid.tsx](../src/client/FileGrid.tsx:296)） |
| 多列操作 | 与网格同一组精简菜单；没有刷新按钮、排序、选择模型、文件操作；**没有** OS 文件拖入（[FileColumns.tsx](../src/client/FileColumns.tsx:198)） |
| 拖拽 | **只有两种**：拖到聊天输入区 = `@file` 引用；OS 文件拖入树 / 侧栏 = 上传。内部移动、复制、拖到文件夹 / 面包屑、拖出下载都未实现；网格与多列没有目录级 drop target（工具栏 `.ignore` 图标除外）（[cursorlike-interactions.ts](../src/client/cursorlike-interactions.ts:18)、[FileTree.tsx](../src/client/FileTree.tsx:747)） |
| 右键菜单 | 三套菜单各自手写，条目与顺序不一致；**空白区右键不存在**；网格 / 多列右键不先收敛选择（因为还没有选择） |
| 快捷键 | 树形文件区只有 `Ctrl+L`（引用）与 `Esc`（清空选择）；网格 / 多列只有 `Backspace` / `Alt+Left` 返回；**没有** `F2`、`Delete`、`Ctrl+A`、`Ctrl+C/X/V`、`F5`、`Shift+F10`（[FileTree.tsx](../src/client/FileTree.tsx:2193)） |
| 文件操作 | 树形有新建 / 重命名 / 删除 / 上传 / 下载 / 打包；**没有复制、剪切、粘贴、移动、复制副本**；删除永久、无回收站；重命名只能同目录改名 |
| Host 能力 | `fs.rename`（仅同目录改名）、`fs.remove`、`fs.mkdir`、`fs.createFile`、`/sidebar/upload`、`/sidebar/archive`；**没有 `fs.move` / `fs.copy`**（[api.ts](../src/client/api.ts:473)、[fs-operations.ts](../src/fs-operations.ts:301)） |
| 忽略 / 排除 | `.ignore` 由客户端读成 exclude 模式，和 `explorerExclude` 一起交给 Host 列目录时过滤，三种视图都受益；隐藏项只做变暗（`entry.hidden`） |

**结论**：文件浏览器现在仍是「树形全能，网格 / 多列只读」。用户感知到的缺口集中在四件事：

1. **展示模式不够**：没有列表 / 详细信息这类适合快速扫读的视图；排序也只有树形有。
2. **拖拽语义不全**：只能引用和上传，不能把文件拖进文件夹完成移动，也没有复制拖拽。
3. **右键菜单不统一**：网格 / 多列菜单是残版，空白区没有菜单，三份实现会继续漂移。
4. **文件操作停在树形**：没有复制 / 剪切 / 粘贴 / 移动，`F2` / `Delete` / `Ctrl+A` 也没接；网格 / 多列没有任何变更操作。

## 1. 展示模式（视图）需求

### 1.1 目标视图清单

| 视图 | 现状 | 定位 | 本轮 |
|---|---|---|---|
| 树形 `tree` | 已有 | 层级浏览、跨目录看结构、Git 着色、批量选择 | 保留，补齐快捷键与菜单一致性 |
| 图标网格 `grid` | 已有 | 桌面式大图标、缩略图、单目录浏览 | 保留，补齐操作 / 选择 / 拖拽 / 排序 |
| Miller 多列 `columns` | 已有 | 多级目录并排、快速横向穿梭 | 保留，补齐操作 / 选择 / 拖拽 / 排序 / 刷新 |
| 列表 / 详细信息 `list` | **缺失** | 单目录、紧凑行、可排序的元信息（名称 / 修改时间 / 大小 / 类型 / Git） | **新增 P0** |
| 紧凑树 / 小图标列表 | 缺失 | 更密集的树或图标 | P2，暂不做 |

**列表视图规格（新增）**

- 单目录浏览，与网格一致：面包屑 + 返回 + 刷新；不要在列表里再实现一棵递归树（递归需求继续用树形）。
- 行高 **28px**，16px 文件图标，文件夹在前；正文 12px，符合现有原生尺度（参见 [2026-09-27-files-changes-uiux.md](plans/2026-09-27-files-changes-uiux.md) §1）。
- 列：`名称`（必选）、`修改时间`、`大小`、`类型`、`Git 状态`（有 Git 时）。文件夹的大小 / 类型显示为 `—`。
- 表头可点击排序（升 / 降切换），排序状态与树 / 网格共享（§1.3）；列宽本轮固定，列宽拖拽放 P1。
- 单击文件夹进入、单击文件打开（与网格保持同一手感）；`Ctrl` / `Shift` 只改选择、不打开。
- 支持多选、右键、空白区菜单、`F2` / `Delete` / `Ctrl+A` / 复制粘贴、内部拖拽、OS 文件拖入、上传、下载 / 打包。
- 大目录超过 500 行时做虚拟滚动（或至少分页 / 截断提示），不能一次渲染数千行。
- 空目录、加载中、加载失败、被截断各有独立提示；隐藏项变暗而不是消失。

### 1.3 排序、隐藏与过滤

- 三种（四种）视图共用同一套比较器：`name` / `type` / `mtime` / `size` × 升序 / 降序 × 文件夹优先；实现上复用 [file-tree-sort.ts](../src/client/file-tree-sort.ts:1)，不要在网格 / 列表里另写排序。
- 排序入口统一放在工具栏排序菜单；列表视图的列头点击也写入同一状态。
- 排序状态**按工作区记忆**（`cwd` 为 key，持久化到 `localStorage` 或插件 prefs；两者选其一但不要两套）。
- 视图切换 / 刷新 / 目录监听后保持排序与滚动位置；排序变化时保留选择（按绝对路径）。
- 隐藏项：保持「变暗显示」；是否新增「显示隐藏项」开关放 P1。`.ignore` 与 `explorerExclude` 仍然只由 Host 过滤，前端不重新解释规则。
- 搜索：现有全局名称搜索保持；本轮不新增「仅过滤当前目录」的输入框（P2）。搜索结果点击仍按现有逻辑打开 / 展开。

### 1.4 视图切换与持久化

- 工具栏提供明确的视图切换（分段控件或带 tooltip 的循环按钮均可）；按钮必须能看出当前视图名称，而不是只有一个图标。
- 视图偏好**按工作区记忆**（key 含 `cwd`），首次进入回退到全局默认；迁移现有 `dsh-cursorlike-sidebar:files-view` 的值一次。
- 默认视图：保持现有「图标网格」为默认（除非用户另选）；树形 / 多列 / 列表各自记住上次选择。
- 网格图标尺寸（Ctrl+滚轮）已存在，保持；列表行高不参与缩放。

### 1.5 布局、性能与状态

- 切换目录 / 视图 / 工作区时取消上一请求（`AbortController`），旧响应不得覆盖新目录。
- 保留现有 level 缓存、目录监听与 `truncated` 提示；网格 / 多列 / 列表在刷新后保留滚动与选择，选择中已消失的路径要剪掉。
- 缩略图只对图片扩展名、且图标尺寸 ≥ 64px 时加载；限制并发与失败占位，避免大目录同时发数百个请求。
- 网格 / 多列 / 列表的加载、错误、空态使用同一套 `Notice` / 错误条组件，不各写一套。
- 响应式：列宽 / 图标列数随面板宽度变化；极窄宽度下至少保持名称可读，不出现横向整页滚动（列表可选择隐藏次要列）。

### 1.6 键盘、焦点与无障碍

- 文件区采用 roving tabindex：方向键在条目间移动焦点，`Home` / `End` 到首尾，`PageUp` / `PageDown` 翻页，`Enter` 打开 / 进入，`Space` 切换选择，`Esc` 清空 / 取消行内编辑。
- `F2` 重命名、`Delete` 删除、`Ctrl+A` 全选、`Ctrl+C/X/V` 复制 / 剪切 / 粘贴、`F5` 刷新、`Shift+F10` 或菜单键打开右键菜单。
- 焦点在 `input` / `textarea` / `contenteditable` / 终端 / 聊天输入框时，以上快捷键一律不拦截；`isComposing` 时同样不拦截。
- 行 / 格输出 `aria-selected`；网格与列表使用 `role="listbox"` / `option` 或等价语义；树形使用 `tree` / `treeitem`（现有语义若不同，本轮统一）。
- 所有仅图标按钮有 `aria-label` 与 `title`；拖拽与批量操作有 `aria-live` 摘要。

### 1.7 验收

- 工具栏可切换到列表视图；刷新后保持上次视图；不同工作区互不串台。
- 列表视图显示名称 / 修改时间 / 大小 / 类型（有 Git 时含状态），点击表头可排序，文件夹在前。
- 网格 / 多列与树一样能排序，且排序状态在切换视图后保持。
- 大目录不一次性渲染全部行；加载失败 / 截断 / 空目录都有可见提示。
- 方向键可在条目间移动焦点；`Enter` / `Space` / `Esc` 行为符合 §1.6。

## 2. 拖拽需求

### 2.1 拖拽语义总表

| 拖拽来源 → 目标 | 结果 | 现状 |
|---|---|---|
| 文件区条目 → 聊天输入区 | 插入 `@file` / `@folder` 引用（多选时多条） | ✅ |
| 文件区条目 → `.ignore` 眼睛图标 | 把路径追加到根 `.ignore` | ✅（已支持多选批量追加） |
| 文件区条目 → 文件夹行 / 格 / 列头 / 面包屑 / 空白区 | **移动**（默认）或 **复制**（按修饰键） | ❌ 本轮 |
| 文件区条目 → 另一个文件区视图的文件夹 | 同上，跨视图一致 | ❌ 本轮 |
| OS 文件 / 文件夹 → 文件区空白 / 文件夹 / 面包屑 | **上传** 到该目录 | 树 ✅；网格 / 多列 / 列表 ❌ |
| 文件区条目 → 编辑器 / 标签栏 | 在编辑器中打开（可选） | ❌ P1 |
| 文件区条目 → 终端 | 插入路径（可选） | ❌ P1 |
| 文件区条目 → OS 桌面 / 资源管理器 | 下载 / 导出（可选） | ❌ P2，需确认 |

**互斥规则**：一次拖拽在**落地时只能执行一种意图**。实现上允许一次 `dragstart` 同时写入多种表示（引用载荷 + 内部文件载荷），由 drop 目标决定读哪一种：聊天只读引用载荷，文件区文件夹 / 空白只读内部文件载荷，`.ignore` 两者都接受。**禁止**文件区目标把引用载荷误判成移动，也禁止聊天把内部文件载荷误判成引用。

### 2.2 内部拖拽：移动与复制

**入口与手势**

- 从树形行、网格格、多列行、列表行都可以拖起；拖起的集合 = 当前选中集合（若被拖项在选中集合内），否则 = 被拖的单项。
- 默认手势是**移动**（符合资源管理器同盘拖拽直觉）；按住 `Ctrl`（macOS `Cmd`）拖拽 = **复制**；`Shift` 强制移动（可留作兼容，不强制实现）。
- 拖动过程中光标 / 幽灵图标显示 `移动 N 项` / `复制 N 项`；非法目标显示禁止光标并不高亮。
- 拖起后 `Esc` 取消；拖到窗口外松手不执行任何操作。

**Drop 目标**

- 文件夹行 / 格 / 列表行：目标是该文件夹本身。
- 文件行 / 格 / 列表行：目标是其父目录（与现有树的上传语义一致）。
- 多列表头、当前列的空白区：目标是该列目录。
- 面包屑任一段：目标是该段目录。
- 网格 / 列表的空白区：目标是当前目录。
- 树形空白区：目标是工作区根（当前树已有「拖 OS 文件到根部上传」的行为，内部拖拽沿用）。
- 目标高亮使用现有 token（`explorerRowDropTarget` 一类的语义），必须能区分「移动到此处」与「上传到此处」。

**自动展开与滚动**

- 悬停折叠的文件夹 **600ms** 后自动展开（仅树形；网格 / 多列 / 列表不展开）。
- 拖到文件区上 / 下边缘 32px 时自动滚动；多列拖到最右列边缘时横向滚动。
- 自动展开 / 滚动可被 `Esc` 或移出目标取消。

**合法性校验（客户端先判，Host 再判）**

- 源是工作区根 → 禁止（不能移动 / 复制根）。
- 目标是文件或不存在 → 禁止。
- 目标是源自身，或源是文件夹且目标在其子树内 → 禁止（避免 `EINVAL` 和半途状态）。
- 源与目标相同目录且不改名 → 不执行（复制时自动生成 `foo copy` 名称）。
- broken symlink 不可拖；拖拽期间有操作在飞（上传 / 删除 / 移动）时禁用新拖拽。
- 跨会话 / 跨工作区：不执行，提示「不能跨工作区移动」。

**执行与反馈**

- 多项拖拽串行执行，不并发打爆 Host；执行期间显示进行中提示或进度，禁止重复触发。
- 目标已存在同名条目：**不静默覆盖**。弹出冲突对话框：`保留两者（自动重命名）` / `跳过` / `取消`；可勾选「对全部冲突应用」。`替换` 仅对单文件开放，且必须二次确认；文件夹不做合并 / 替换（P1 再评估）。
- 部分失败：成功的保留，失败项汇总成「成功 N / 失败 M」错误条，列出前几个路径；不回滚（Host 无事务）。
- 成功后：刷新源目录与目标目录（网格 / 列表 / 多列重新拉取；树形剪枝 / 插入或依赖目录监听），选择跟随到新路径，滚动位置尽量保持，已打开的相关标签页跟随新路径（复用 [tree-mutations.ts](../src/client/tree-mutations.ts:1)）。
- 跨磁盘移动（`EXDEV`）：本轮不自动「复制后删除」，显示明确错误；P1 再提供「复制并删除源」选项。
- P1：移动 / 复制完成后显示短暂「已移动 N 项 · 撤销」提示，撤销 = 反向移动；冲突时不提供撤销。

### 2.3 OS 文件拖入（上传）

- 树形已支持；本轮把同样的 drop 能力补到网格、列表、多列（列本身、列头、空白区）。
- 空白区 / 当前目录 = 上传到当前目录；文件夹行 / 格 = 上传到该文件夹；面包屑段 = 上传到该段目录。
- 保留文件夹递归与相对路径（复用 [upload.ts](../src/client/upload.ts:1)）；显示统一的拖拽高亮与「上传到 `<dir>`」提示。
- 复用 `UploadOverlay` 的进度 / 取消；进行中禁止再次拖入，`dropEffect = 'copy'`。
- 冲突策略与现有上传保持一致（当前为同名覆盖）或与 §2.2 统一；无论哪种，完成后必须提示「已覆盖 N 项」。**待确认**（§9）。
- 拖入非文件类型（文本、URL、聊天消息）不得触发上传，也不得被文件区吞掉。

### 2.4 拖出 / 引用

- 拖到聊天：保持现有引用 payload（多选时全部作为引用），不得因为新增内部拖拽而退化。
- 拖到 `.ignore`：保持现有追加逻辑（已按多选批量追加、去重）；接收方同时接受引用载荷与内部文件载荷，本轮补网格 / 多列 / 列表的拖拽入口与测试。
- 拖到编辑器 / 标签栏打开（P1）：payload 只带路径，由宿主或编辑器接住；不做文件移动。
- 拖到终端插入路径（P1）：优先工作区相对路径，必要时绝对路径；是否做取决于终端是否已有 drop 契约。
- 拖到 OS 下载（P2）：需要浏览器 `DownloadURL` 支持，且大文件夹不应触发；先确认再排期。

### 2.5 视觉与可访问性

- 拖拽幽灵 / 徽标：多选时显示数量，拖动时半透明；目标行 / 格整行高亮，不用大面积遮罩。
- 所有颜色与尺寸走 `--dsw-*` token；不写死颜色（现有遗留的硬编码色本轮不再新增）。
- 拖拽状态变化通过 `aria-live="polite"` 播报「正在移动 3 项到 src/client」；失败通过错误条播报。
- 拖拽不触发文本选择；触摸设备至少保留菜单 / 剪贴板入口（拖拽可降级）。

### 2.6 Host / API 变更

本轮需要新增两条路由（命名与现有 `fs.*` 一致）：

| 路由 | 请求 | 响应 | 说明 |
|---|---|---|---|
| `fs.move` | `{ sessionId, cwd, path, toDir, name? }` | `{ path }` | 移动一个条目到目录；`name` 缺省保留原 basename |
| `fs.copy` | `{ sessionId, cwd, path, toDir, name?, recursive? }` | `{ path, entries? }` | 复制文件或目录；目录默认递归；返回实际复制条目数 |

约束：

- 复用 `resolveTarget` / 现有路径解析与 root 保护；源与目标都必须是绝对路径或会话相对路径（[path-security.ts](../src/path-security.ts:56)）。
- 源必须是已存在条目；`toDir` 必须是已存在目录；`name` 必须是单段名；目标已存在 → `409`（`fs-error` / `fs-conflict`），绝不静默覆盖。
- 源是工作区根 → 拒绝；源是目录且目标在其子树内 → 拒绝；目标路径与源相同：移动为 no-op，复制由客户端先生成不冲突名称（Host 仍拒绝已存在的目标）。
- `move` 用 `fs.rename`；跨设备 `EXDEV` → 明确错误（不自动复制 + 删除）。
- `copy` 递归复制时限制条目数与总字节数（建议与归档一致：10 000 条目 / 256 MiB），超限立即中止并返回可读错误；不跟随指向工作区外的符号链接（复制链接本身或拒绝，需在实现前定；建议复制链接本身并记录）。
- 成功后分别失效源目录与目标目录的缓存；移动需要让已打开的标签页跟随（客户端 `tree-mutations`），复制不重定向标签页。
- 两个路由都要有 Host 单测（root / 已存在 / 自身子树 / 跨设备 / 递归上限）与路由级测试；客户端补组件测试。
- 客户端新增 `api.fsMove(scope, path, toDir, name?)` 与 `api.fsCopy(scope, path, toDir, name?)`；不新增第三方依赖。

### 2.7 验收

- 把文件从树拖到另一个文件夹行 → 文件被移动；源目录与目标目录都刷新；标签页路径跟随。
- 按住 `Ctrl` 拖拽 → 复制；原文件仍在，目标出现副本。
- 把文件夹拖进自己的子目录 → 被拒绝并有提示，不产生半截目录。
- 多选 3 项拖入目录 → 3 项串行移动；失败项汇总；选择跟到新位置。
- 目标已有同名项 → 冲突对话框出现；选择「保留两者」后新名不冲突；选择「跳过」不改变目标。
- OS 文件拖到网格 / 列表 / 多列空白区 → 上传到当前目录；拖到文件夹 → 上传到该文件夹；有进度与取消。
- 拖到聊天仍然是引用，不会触发移动；拖到 `.ignore` 仍然是忽略，不会触发移动。
- 移动 / 复制期间不能再次发起同类操作；失败不静默。

## 3. 右键菜单需求

### 3.1 单一动作表

现状是三份菜单各写一遍（树 / 网格 / 多列）。本轮先抽出**一份客户端动作描述表**，所有视图、右键菜单、工具栏、空态按钮都从它渲染：

```ts
interface FileAction {
  id: string
  label(): string
  icon?: ReactNode
  shortcut?: string
  danger?: boolean
  /** false = 隐藏；string = 显示但禁用，并作为 title 说明原因 */
  enabled(ctx: FileActionContext): boolean | string
  run(ctx: FileActionContext): void | Promise<void>
}
```

- `FileActionContext` 至少包含：`view`、`scope`、`cwd`、`currentDir`、`target`（被右键的条目或 `null` = 空白区）、`selection`、`busy`、`clipboard`、`api`。
- 菜单由 `menuFor(context)` 生成：动作表 + 分组 + 分隔线；**禁止**在视图组件里手写 `<button>` 菜单项。
- 现有树形菜单迁移到动作表，行为保持不变；网格 / 多列 / 列表直接复用。
- 动作 id 稳定，便于测试与快捷键映射。

### 3.3 行为、定位与键盘

- 菜单通过 portal 渲染到 `document.body`，按鼠标位置打开；靠近视口右 / 下边缘时翻转或夹紧，绝不超出视口。

- 禁用项保留在菜单中并给出原因（例如「多选时不能重命名，请先选择一项」），不要静默消失（除非整组不适用）。
- 动作执行期间菜单立即关闭，失败通过文件区错误条 / toast 显示，不只在 console。

- 空白区菜单的「当前目录」：网格 / 列表 / 多列 = 当前目录；树形 = 工作区根（或右键所在的可见层级，若实现成本低）。
- 空白区右键不改变选择（或先清空选择，需统一；建议保留选择，避免误清空）。

### 3.5 工具栏

- 新增常驻：新建文件、新建文件夹。
- 有选择时启用：重命名（恰好 1 项）、删除、复制 / 剪切（可选）。
- 上传文件 / 文件夹保持；刷新、视图切换、排序、`.ignore` 保持。
- 空间不足时收进 `⋯` 溢出菜单；所有按钮有 label / tooltip / 快捷键提示。

### 3.6 验收

- 三种（四种）视图的同一动作菜单项名称、顺序、图标一致；网格 / 多列不再只有 5 项。
- 空白区右键出现菜单；新建 / 上传 / 粘贴作用于当前目录。
- 多选右键出现批量删除 / 复制 / 剪切 / 压缩 / 复制路径；重命名不可用并说明原因。
- 菜单不会超出视口；子菜单在边缘自动翻转。
- `Shift+F10` 可打开当前焦点项菜单并用键盘执行。

### 4.2 选择模型（统一）

- 选择 key = 绝对路径；锚点 = 最近一次单选；`Ctrl` / `Cmd` 切换单项，`Shift` 按当前可见顺序区间选择，`Ctrl+A` 全选当前可见项，`Esc` / 空白单击清空。
- 单击语义保持现有手感：树形 = 展开 / 折叠或打开，网格 / 多列 / 列表 = 进入或打开；修饰键只改选择、不触发打开。
- 右键未选中项先收敛到该项；右键已选中项保留整个选区。
- 选择跨目录保留（网格 / 列表切换目录再返回时恢复）；多列允许跨列选择，但批量条按列分组显示（**待确认**）。
- 删除 / 移动 / 重命名后剪掉失效路径；重命名 / 移动把选择跟到新路径。
- 批量条显示「已选 N 项」+ 复制路径 / 删除 / 复制 / 剪切 / 压缩 / 清除；树形现有批量条迁移到同一组件。

### 4.3 新建

- 入口：工具栏、文件夹右键、空白区右键、列表 / 网格 / 多列的当前目录。
- 行内输入：默认名走 i18n（`untitled` / `新建文件夹`），重名自动避让 `untitled-1`；`Enter` 提交、`Esc` 取消、失焦提交（与现有树一致）。
- 校验：空名、`.` / `..`、路径分隔符、Windows 非法字符、保留设备名；客户端先校验，Host 再校验并原样显示错误。
- 创建文件后直接打开；创建文件夹后进入（网格 / 列表 / 多列）或展开（树）。
- 失败时输入框保持打开并显示行内错误，不刷新列表。

### 4.4 重命名

- 入口：`F2`、右键、工具栏（仅单选）。
- 行内编辑：预选主文件名、保留扩展名；`Enter` / 失焦提交，`Esc` 取消；IME 组合期间不提交。
- 成功后标签页跟随、选择跟到新路径、滚动不跳；失败保持输入框并显示错误。
- 不做批量重命名（非目标）。

### 4.5 删除

- 入口：`Delete`、右键、工具栏、批量条。
- 确认弹窗：单个显示文件名；批量显示数量 + 前 5 个路径；目录额外说明「文件夹，包含的子项会被递归删除」；文案必须说明**永久删除、不可恢复**（Host 没有回收站）。
- 目标有未保存编辑器草稿时额外提示；确认后关闭相关标签页。
- 批量逐条串行，失败项汇总、不回滚；成功后清空选择并刷新。
- 根目录、根行拒绝删除。

### 4.6 复制、剪切、粘贴、复制副本、移动

- **剪贴板模型**：客户端内存剪贴板（按会话 / 工作区隔离），记录 `{ mode: 'copy' | 'cut', paths, scope }`；切换会话或工作区时清空。本轮不做系统级「真文件剪贴板」（跨应用粘贴文件），只保证插件内 `Ctrl+C/X/V`。
- `Ctrl+C` 复制所选，`Ctrl+X` 剪切（行 / 格变暗），`Ctrl+V` 粘贴到当前目录或右键的文件夹。
- 粘贴执行 `fs.copy` / `fs.move`；粘贴后清空剪切态（复制态可保留，允许连续粘贴）。
- 目标重名 → 冲突对话框（同 §2.2）；粘贴目录到自身子树 → 拒绝。
- 复制副本（P1）：在同一目录生成 `foo copy.ts` / `foo copy 2.ts`，不覆盖；`Ctrl+D` 可选。
- 「移动到…」对话框（P1）：选择一个已存在文件夹，交互等价于拖拽移动；不做跨工作区。
- 大目录复制显示进度 / 忙碌态；可取消（Host 请求 abort 或至少停止后续条目，需在实现前定）。
- 所有操作完成后刷新两个目录并保持选择 / 滚动。

### 4.7 上传、下载、打包

- 上传：工具栏、右键、拖入三种入口统一到 `TreePanel` 的上传会话；网格 / 多列 / 列表的默认目标是当前目录。
- 上传同名冲突：保持现状（覆盖）或统一到 §2.2 的冲突对话框；无论哪种都必须有结果提示。**待确认**。
- 下载：单文件下载保持；目录 / 多选走压缩下载（现有 `/sidebar/archive`）；菜单在四种视图中一致。
- 大文件 / 大目录有忙碌态与失败错误；不允许静默失败。

### 4.8 打开、定位与引用

- 打开：单击 / `Enter` 打开；右键提供新标签、侧边、打开方式；目录可进入。
- 定位：网格 / 多列 / 列表右键「在树中定位」→ 切到树形、展开祖先、滚动并高亮该行。
- 引用：右键 / 行尾按钮 / 拖到聊天 / `Ctrl+L` 插入 `@file`；目录引用保持现有行为。
- 「在文件管理器中显示」复用宿主 open-in-app；不可用时退回插件 open-with 的 explorer 目标。

### 4.9 快捷键（文件区聚焦时）

| 键 | 动作 | 备注 |
|---|---|---|
| `F2` | 重命名当前项 | 恰好 1 项选中；多选禁用并提示 |
| `Delete` | 删除选中项 | 走确认；`Backspace` 保持「返回上级」 |
| `Ctrl+A` / `Cmd+A` | 全选当前可见项 | 输入框内不劫持 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴 | 文件区专用，不劫持编辑器文本操作 |
| `Ctrl+Shift+C` | 复制所选路径 | 与批量条同源 |
| `F5` | 刷新当前目录 | 与工具栏刷新同源 |
| `Enter` | 打开 / 进入 | 已有 |
| `Space` | 切换选择 | 焦点在条目上 |
| `Esc` | 取消行内编辑 / 清空选择 / 取消拖拽 | 已有部分 |
| `Shift+F10` / 菜单键 | 打开右键菜单 | 焦点在条目上 |
| `Alt+Left` / `Backspace` | 返回上级 | 网格 / 列表 / 多列已有，列表补齐 |
| `Ctrl+滚轮` | 图标 / 缩略图缩放 | 网格已有 |

所有快捷键都要有输入框 / 终端 / 聊天输入区的守卫；`event.defaultPrevented` 或 `isComposing` 时直接返回。

### 4.10 操作状态、错误与并发

- 每个操作有忙碌态：进行中禁用同一入口与冲突操作，防止重复提交。
- 错误统一进文件区错误条 / toast，包含路径与 Host 返回文案；不吞异常、不只打 console。
- 批量操作串行，结束后汇总「成功 N / 失败 M」；失败项可重试（保留选择）。
- 操作触发的刷新与目录监听去重：优先让 Host 操作直接失效缓存 + 重新拉取，监听事件只做兜底。
- 会话 / 工作区切换时取消在飞请求并丢弃过期结果（沿用现有 generation guard）。

### 4.11 持久化与撤销

- 选择、剪贴板、进行中操作**不跨刷新保留**；跨工作区必须清空。
- 删除不可撤销（无回收站）；移动 / 重命名 / 新建可提供短暂「撤销」提示（P1），刷新后失效。
- 不做跨重启的完整撤销栈。

### 4.12 i18n 与无障碍

- 所有新文案进入 20 份词典（`zh`、`en` + 18 种第三方），`tests/locales.spec.ts` 必须绿。
- 输入框、菜单、批量条、冲突对话框都有 `aria-label` / `role`；快捷键提示只在真实实现后展示。
- 列表 / 网格的条目在焦点移动时播报名称与类型；批量结果用 `aria-live` 播报。

### 4.13 验收

- 四种视图里 `F2` 都能就地重命名，扩展名不被选中，`Enter` 生效、`Esc` 放弃。
- `Delete` 弹确认，确认后文件消失、相关标签页关闭；取消则无变化。
- `Ctrl+C` / `Ctrl+X` / `Ctrl+V` 能在目录之间复制 / 移动；冲突不静默覆盖；剪切态有视觉反馈。
- `Ctrl+A` 全选当前可见项，`Esc` 清空；修饰键单击只改选择、不打开。
- 网格 / 多列 / 列表右键菜单与树一致，空白区菜单可新建 / 上传 / 粘贴。
- 拖 OS 文件到任意视图能上传到目标目录，冲突有提示。
- 批量删除 / 移动只确认一次，逐条执行并汇总失败。
- 所有新文案进入 20 份词典；类型检查、单测、mount lane 通过。

## 6. 实施顺序建议

| 阶段 | 内容 | 依赖 |
|---|---|---|
| **A. 入口统一（无 Host 变更）** | 动作表 + 菜单生成器；网格 / 多列 / 列表接入右键与空白菜单；`F2` / `Delete` / `Ctrl+A` / `F5`；工具栏新建 / 删除 / 重命名；OS 文件拖入网格 / 多列 / 列表；选择模型统一 | 无 |
| **B. 文件搬运** | `fs.move` / `fs.copy` + `api`；内部拖拽移动 / 复制；复制 / 剪切 / 粘贴；冲突对话框；标签页跟随；批量汇总 | A + Host 路由 |
| **C. 视图补全** | 列表 / 详细信息视图；四视图排序；键盘导航；虚拟滚动；按工作区记忆视图 / 排序 | A 可并行，B 不阻塞 |
| **D. 增强** | 拖到编辑器 / 终端；拖出下载；移动 / 复制撤销；复制副本；隐藏项开关；列宽拖拽；移动到…对话框 | B/C |

建议先做 **A**，因为它能立刻消除「网格 / 多列只能看不能操作」的落差；**B** 是本轮真正的能力缺口；**C** 的列表视图可与 A 并行；D 按确认结果排期。

## 7. 总验收清单

- [ ] 四种视图（树 / 网格 / 多列 / 列表）共享同一选择模型、同一动作表、同一套快捷键。
- [ ] 网格 / 多列不再只有「打开 / 引用 / 复制路径」；右键、空白区、批量操作齐全。
- [ ] 列表视图可按名称 / 时间 / 大小 / 类型排序，文件夹在前，大目录不卡死。
- [ ] 内部拖拽可移动 / 复制到文件夹行、面包屑、列头、空白区；非法目标被拒绝；冲突不静默覆盖。
- [ ] OS 文件可拖入任一视图上传到正确目录；有进度、可取消、有结果提示。
- [ ] `F2` / `Delete` / `Ctrl+A` / `Ctrl+C` / `Ctrl+X` / `Ctrl+V` / `F5` 在文件区可用，且不劫持输入框、终端、聊天。
- [ ] 新建、重命名、删除、上传、下载 / 打包、复制 / 剪切 / 粘贴、移动在所有视图中一致可用。
- [ ] 操作失败有可见错误；批量操作有「成功 N / 失败 M」汇总；进行中禁止重复提交。
- [ ] 已打开标签页在重命名 / 移动后跟随新路径，删除后关闭。
- [ ] 菜单与弹窗不超出视口，键盘可达；危险操作有确认与不可恢复说明。
- [ ] 所有新文案进入 20 份词典；`pnpm typecheck` / `lint` / `test` / `build` / mount lane 通过。

## 8. 非目标

- **回收站 / 撤销删除**：Host 没有回收站，删除仍是永久操作（保留二次确认）。
- **批量重命名**、正则重命名。
- **跨工作区 / 跨会话移动或复制**；不做云端 / 远程文件搬运（SSH 场景仍只做打开与展示）。
- **系统级文件剪贴板**（从资源管理器复制文件、在插件里粘贴），本轮只做插件内剪贴板；是否接系统剪贴板见 §9。
- **完整资源管理器**：不做分组、标签、文件属性页、权限 / ACL 编辑、驱动器管理。
- **文件夹合并 / 替换式覆盖**：本轮冲突只提供保留两者 / 跳过 / 取消，不做危险合并。
- **自动「复制后删除」的跨盘移动**（P1 再评估）。
- **改变 DSH 原生聊天拖放行为**：拖到聊天仍是引用，不改成上传或移动。
