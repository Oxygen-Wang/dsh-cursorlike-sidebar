# 聊天引用与忽略规则

更新：2026-10-18。入口：[分类索引](requirements-zh.md)。

## 文件与选中文字引用

- [x] Markdown 预览浮动入口提交选中文字，任务勾选框不再干扰多行源位置匹配；按钮与 Ctrl/Cmd+L 均有组件回归。
- [x] 入口显示「Ctrl+L 添加到对话」，定位当前编辑/预览区域右下角，使用高对比底色、边框、阴影与键盘焦点提示。

- [x] 编辑器 Ctrl/Cmd+L、选中文字拖动、添加到对话按钮共享文件/行号引用，不默认附带代码正文。
- [x] 文件区引用文件/目录；网格/多列新增 Ctrl/Cmd+L，多选逐项引用。
- [x] 文件拖动同时携带自定义 payload 和文本回退；聊天 drop 保持引用语义，不触发磁盘移动。
- [ ] P0：真实宿主主聊天、侧边对话、会话切换后的输入框焦点与引用落点回归。
- [ ] P1：引用失败可见反馈、工作区外路径与远程路径的统一显示、批量引用与重复引用策略。

依据：`cursorlike-interactions`、`selection-reference`、`reference-in-chat`、`file-tree-reference-tail` 测试。

## 忽略

- [x] 点击 `.ignore` 入口前确保文件存在：仅在 ENOENT 时新建空文件再打开，已有规则保持不变，其他窗口先创建时重新读取，权限失败显示提示。拖入忽略入口也使用同一创建逻辑。

- [x] 根 `.ignore` 的正向 glob 与配置 exclude 合并，作用于三视图和文件名搜索。
- [x] 工具栏 `.ignore` 入口和拖入条目追加规则已有实现；文件搬运捕获明确让该落点继续处理忽略。
- [x] 忽略仅影响展示与检索，不删除文件，不修改 Git。
- [ ] P0：`.ignore` 外部修改后自动重读；当前读取依赖 refreshTick，不能标为完整实时读取。
- [ ] P0：多选/右键添加忽略、从 `.gitignore`/`.cursorignore` 导入并显示结果。
- [ ] P1：`!` 例外规则、子目录规则、超过 64 条规则的可见提示。
- [ ] P1：忽略写入失败显示给用户；现有 dropToIgnore 的失败主要写到 console。

不默认自动读取 `.gitignore` 或 `.cursorignore`，沿用先前明确的“主动导入”范围。
