# 文件浏览与文件操作

更新：2026-10-18。保留现有树、网格、多列的展示。需求入口：[分类索引](requirements-zh.md)。

## 左键、选择与键盘

- [x] 网格顶部返回按钮和“返回上级”方块支持作为拖放目标，移动到父目录；面包屑仍可拖入对应目录。根目录不提供越出工作区的父目录落点。

- [x] 普通左键继续打开文件/进入目录，Ctrl/Cmd 点击切换选择，Shift 在当前可见列表选择范围。
- [x] 网格不额外注册重复打开文件的双击回调；连续点击的第二次 click 不再重复调用打开。
- [x] 网格/多列显示选择状态和批量条，Escape 清空选择。
- [x] Ctrl/Cmd+A 选择当前文件区可见项；树形使用可见行，网格使用当前目录，多列按当前列。
- [x] F2 重命名、Delete 打开永久删除确认，Ctrl/Cmd+L 引用选中文件。
- [x] 网格/多列支持方向键、Home/End、Shift 扩展选择与焦点滚动；网格上下移动按显示列数。
- [x] F5 刷新文件区，不刷新整个网页；输入框保留自身按键行为。
- [ ] 树形补齐完整的方向键导航、目录左右展开与 roving focus。
- [ ] 多列跨列统一选择、左右键切换列；空白点击清选区的边界进一步对齐。
- [ ] 文件中键打开新标签、双击固定预览标签；须先明确插件预览标签状态，不能简单重复调用打开。

## 右键菜单

- [x] 网格/多列共用 `file-browser-actions.tsx`，文件和空白区都有基础菜单。
- [x] 右键未选中行收敛到该行，右键选中行保留多选。
- [x] 菜单包含打开、新标签/侧边打开、引用、复制相对/绝对路径、复制、剪切、粘贴、下载、新建、重命名、删除、刷新。
- [x] Shift+F10 / ContextMenu 键可打开菜单；使用宿主 Menu 的 portal、键盘和视口定位能力。
- [x] 树形增加空白区域菜单与文件剪贴板菜单。
- [ ] 树形也迁移到同一动作表；目前保留原有打开方式与打包逻辑，因此尚非所有菜单完全一致。
- [ ] 网格/多列补齐宿主与插件的“打开方式”、在系统文件管理器显示、在树中定位。
- [ ] 网格/多列补齐多文件/文件夹压缩下载，树形已经存在该能力。

## 文件操作

- [x] 网格/多列新建文件/文件夹、重命名、单项/批量删除、单文件下载。
- [x] 新建与重命名用名称对话框，失败在对话框/文件区显示；重命名默认选中文件名主体。
- [x] 删除先确认“移到恢复区，可撤销”，确认前不发删除请求；已成功项移出选择，失败项保留以便重试。
- [x] 新建文件后打开；重命名/移动通知 `onPathRenamed`，删除通知 `onPathDeleted`，复用已有标签协调机制。
- [x] Ctrl/Cmd+C/X/V 与右键复制/剪切/粘贴使用插件内剪贴板，绑定 sessionId + cwd；不混入系统文字剪贴板。
- [x] 多选同时包含目录和子项时只搬运顶层项，避免重复搬运。
- [x] 后端 `fs.transfer { path, dir, mode }`：copy 递归复制、move 改变所在目录；复用现有路径解析和工作区根保护。
- [x] 复制重名生成 `name (1).ext` 等副本，移动重名返回冲突；不覆盖已有目标。
- [x] 拒绝目录进入自身/子目录，实际路径检查也覆盖目标目录符号链接；串行化内部并发搬运请求。
- [x] 会话/目录切换清空当前选择和对话框；异步完成不写入另一个会话的界面状态。
- [ ] 批量操作完成后显示成功/失败/未执行数量；目前失败显示原因并停止后续项。
- [x] 移动/重命名/复制/新建/删除的持久化撤销/重做、历史面板与批量分组，见[后悔机制](requirements-undo-recovery-zh.md)。
- [ ] 剪切待粘贴的淡化状态、剪贴板完成提示。
- [ ] 复制任务进度、取消、失败后清理部分副本；跨磁盘移动的显式降级方案。
- [ ] 外部程序与本插件同时创建同名目标的竞争处理；目前应用内部排队，外部竞争需继续加强。
- [x] 删除改用恢复区；取消确认不操作磁盘，未保存草稿先保护，恢复时不覆盖同名新文件。
- [ ] 从系统文件管理器复制文件后直接粘贴；本轮仅有插件内文件剪贴板和外部拖入上传。

## 拖放

- [x] 内部文件/文件夹拖到目录，默认移动，Ctrl/Cmd 复制；拖到聊天维持原来的引用语义。
- [x] 目录行、文件行所在目录、网格空白区、网格面包屑、多列列头/空白区可作为目标。
- [x] 网格/多列外部文件拖入与“上传到此”接入 TreePanel 的上传进度/取消/结果提示。
- [x] 网格面包屑支持将上传/内部拖放定向到对应目录。
- [ ] 拖动目标高亮、悬停展开目录、边缘自动滚动、移动前目标预览。
- [ ] 多列面包屑的定向拖放；目前列头可作为目标，顶端面包屑仍需补齐。
- [ ] 拖文件到编辑器标签条打开、拖到编辑器区域分屏打开。
- [ ] 拖路径到终端插入带正确 shell 转义的路径，拖出系统桌面/下载。
- [ ] 真实浏览器验证外部文件夹拖入，特别是宿主捕获监听、文件夹遍历和窄屏落点。

## 刷新、排序与展示

- [x] 工具栏 refreshTick 与名称/类型/文件夹优先排序作用于三个现有视图。
- [x] 多列增加刷新按钮；网格和多列 F5 可用。
- [x] 排序选择在 localStorage 记忆，已有视图选择不会被迁移逻辑强制改回默认。
- [ ] 按工作区分别记忆视图、排序与当前目录；目前为全局偏好。
- [ ] 网格/多列接入目录实时监听；当前支持按钮/F5/窗口重新聚焦刷新。
- [ ] 会话内其他窗口变更后的跨文件窗口同步、跨列变更后失效列路径修复。
- [ ] 时间/大小排序和大目录性能验收。

新增列表、详情视图、列宽拖动属于后续可选增强，不是本轮基础操作的完成条件。
